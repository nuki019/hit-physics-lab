## 1. 项目愿景与核心痛点解决

哈工大大物实验是理工科本科生的核心基础实践课程。在传统实验报告撰写过程中，学生普遍面临以下四大痛点：
1. **数据计算繁琐易错**：四次换向法、逐差法、贝塞尔公式评定 A 类不确定度及有效数字修约流程繁复，手工计算极易产生累积舍入误差；
2. **作图耗时且难以达标**：传统毫米方格纸作图耗费大量时间，且手工选轴、描点、确定最佳拟合斜率常因比例不当或坐标选择不合理被扣分；
3. **报告册粘贴区篇幅受限**：未来技术学院统一发放的 **B5 规格实验报告册**（不同于物理学院版本）版面尺寸特殊（内页约 $176\text{ mm} \times 250\text{ mm}$），有效粘贴安全区域仅 $14.2\text{ cm} \times 18.8\text{ cm}$，普通 A4 纸张直接打印粘贴会导致遮盖页眉校标或页脚页码；
4. **思考题解答深度不足**：思考题缺乏标准物理机理解析与考点对齐，学生容易只知其然不知其所以然。

**HIT Physics Lab** 彻底解决了上述问题：
- **纯前端单页架构**：基于 React 18/19 + TypeScript + Vite + Tailwind CSS 构建，所有科学计算均在浏览器端实时完成，无须任何后端服务器，数据自动暂存本地 `LocalStorage`，安全私密，断网离线也能流畅使用；
- **真实 1:1 物理比例打印引擎**：输出严格符合 $138.0\text{ mm}$ 虚线裁剪框要求的双页报告，提供 $100.0\text{ mm}$ 物理防缩放校验尺，裁剪后可完美贴入 B5 报告册对应章节空白区，严密避让装订线、原标题与页码；
- **模块化插件解耦体系**：定义统一的 `ExperimentPlugin` 规范，实现表格 Schema、计算纯函数、思考题库与图表渲染高度正交，支持持续快速扩充。

### 2.2 打印与裁剪实操指引（防缩放核心要点）

在平台点击右上角 **「打印 / 导出 PDF」** 按钮后，浏览器将自动调起原生系统打印窗口。请务必核对以下关键打印参数：
1. **目标打印机**：选择物理打印机或「另存为 PDF」；
2. **纸张尺寸**：**A4**（$210\text{ mm} \times 297\text{ mm}$）；
3. **边距 (Margins)**：选择 **「无 (None)」**；
4. **缩放 (Scale)**：**必须选择「实际大小 (100%)」**，严禁选择「适合纸张」或「缩放至页面大小」；
5. **背景图形 (Background graphics)**：**务必勾选**（以正确输出 1:1 毫米刻度网格与表格斑马纹）；
6. **物理尺校验**：打印输出后，请使用实体学生直尺测量纸张底部的 **$100.0\text{ mm}$ 校验标尺**。若实测长度恰好为 $10.0\text{ cm}$，表明打印比例 100% 绝对精确；
7. **裁剪贴附**：沿纸张上的灰色虚线与剪刀标志（$\text{✂}$）整齐剪裁，使用固体胶涂抹于背面四周，贴入 B5 报告册对应页码内。

## 3. 核心功能特性矩阵

- **交互式数据录入表 (`DataTable`)**：
  - 自动渲染规范三线表，支持多表格子标签无缝切换（如霍尔效应三张表、液体黏度双表）；
  - 300 毫秒输入防抖自动暂存，刷新页面数据不丢失；
  - 单元格具备非空校验、浮点格式检查与异常极值防御；
  - 提供「载入基准数据」按钮，一键调出教材与薪火笔记实测标准基准数据对拍。
- **高精度科学计算微内核 (`src/core/math/`)**：
  - **最小二乘法回归 (`regression.ts`)**：高精度计算拟合斜率 $k$、截距 $b$、线性相关系数 $r$ 与决定系数 $R^2$；
  - **逐差法计算 (`difference.ts`)**：支持对半配对逐差（消除零点漂移）与平方差逐差（牛顿环消除接触膜厚影响）；
  - **不确定度评定 (`uncertainty.ts`)**：贝塞尔公式计算 A 类样本标准差 $u_A = s/\sqrt{N}$、仪器极限误差折算均匀分布 B 类不确定度 $u_B = \Delta_{\text{仪}}/\sqrt{3}$、合成标准不确定度 $u_c = \sqrt{u_A^2 + u_B^2}$；
  - **有效数字修约 (`formatter.ts`)**：符合国家计量检定规程的四舍六入五凑偶修约算法。
- **KaTeX 分步推导展示 (`MathView`)**：
  - 分步呈现理论公式、实测数值代入过程与最终计算结果，完全满足未来技术学院实验报告书写规范。
- **1:1 毫米刻度矢量拟合图谱 (`PlotCanvas`)**：
  - 严格按照 $73.5\text{ mm} \times 51.5\text{ mm}$ 黄金版面渲染 SVG 矢量图；
  - 包含 1mm 细网格、10mm 主网格、向内刻度线、测量散点与最小二乘拟合直线及 95% 置信带。
- **思考题库与结论编辑**：
  - 预置每门实验官方标准思考题物理机制权威解析；
  - 支持学生根据实操情况自主修改富文本心得与体会。
- **全书 65 实验目录索引与学期规划模态框 (`CatalogModal`)**：
  - 导航栏一键唤出，支持对赵海发第三版全书 65 门实验及本学期 13 门大物实验按关键词、章节、状态实时检索与一键跳转。

## 4. 已上线核心实验解析

平台已原生落地 4 门交互式实验插件，完全涵盖力热、电磁与光学三大领域：

### 4.1 实验一：霍尔效应 (Hall Effect)
- **对应教材**：第三章 综合性实验 实验三十二（书本 p.196，PDF p.211）；
- **数据表格**：
  - 表 1：对称四次换向法测量 $U_H \sim I_s$ 关系（正反向励磁与工作电流切换，彻底消除不等位电势降、爱廷豪森效应、能斯特效应与里纪-勒杜克效应等 4 大副效应）；
  - 表 2：$U_H \sim B$ 线性拟合与第二霍尔灵敏度 $K_{H2}$ 评定；
  - 表 3：螺线管轴向梯度磁场微位移定标（位移与霍尔电势对应关系）。
- **物理计算**：第一霍尔灵敏度 $K_{H1}=94.8\ \mathrm{V/(A\cdot T)}$、第二霍尔灵敏度 $K_{H2}=119.4\ \mathrm{V/(A\cdot T)}$、霍尔系数 $R_H=2.14\times 10^{-2}\ \mathrm{m^3/C}$、载流子浓度 $n=2.91\times 10^{20}\ \mathrm{m^{-3}}$。

### 4.2 实验二：迈克耳逊干涉仪 (Michelson Interferometer)
- **对应教材**：第三章 综合性实验 实验三十六（书本 p.211，PDF p.226）；
- **数据表格**：
  - 表 1：分振幅双光束干涉动镜位移逐差表（每涌出/陷入 150 条干涉环记录微调手轮读数，考虑手轮 $1:20$ 机械减速传动比）；
  - 表 2：气室抽气法条纹计数与压强变化记录表。
- **物理计算**：对半逐差动镜平均位移 $\overline{\Delta d} = 0.04317\ \mathrm{mm}$、测得 He-Ne 激光波长 $\lambda = 575.6\ \mathrm{nm}$、贝塞尔 A 类不确定度 $u_A(\lambda) \approx 8\ \mathrm{nm}$、气压线性回归斜率推导空气折射率 $n = 1.000258$（对比两点法 $n'=1.000252$）。

### 4.3 实验三：光的等厚干涉——牛顿环与劈尖 (Newton's Rings & Wedge)
- **对应教材**：第二章 基础性实验 实验二十二（书本 p.151，PDF p.166）；
- **数据表格**：
  - 表 1：牛顿环暗环读数显微镜左右位置测量表（暗环级次 $m=35 \sim 15$）；
  - 表 2：空气劈尖等厚干涉暗纹条纹位置与间距测量表。
- **物理计算**：
  - 暗环平方差逐差法消除球表面接触膜厚附加光程差畸变，测得平凸透镜曲率半径 $R = 2.41\ \mathrm{m}$，合成不确定度 $u(R) = 0.11\ \mathrm{m}$；
  - **特色防御功能**：提供 $m=19$ 跳变异常点剔除对比开关，一键自适应重拟合为 $R = 2.50\ \mathrm{m}$ 并对比相对偏差；
  - 劈尖条纹均值与微丝直径精确计算：$d = \frac{5 L \lambda}{l} = 86.6\ \mu\mathrm{m}$。

### 4.4 实验五：液体黏度的测定——落球法 (Liquid Viscosity)
- **对应教材**：第二章 基础性实验 实验五（书本 p.70，PDF p.85）；
- **数据表格**：
  - 表 1：5 颗小钢珠在不同方位测量的读数显微镜直径记录表；
  - 表 2：不同温度（$20.0^\circ\mathrm{C} \sim 40.0^\circ\mathrm{C}$）下蓖麻油小球下落时间与黏度测定记录表。
- **物理计算**：
  - 小球算术综合平均直径 $\bar{d} = 2.011\ \mathrm{mm}$ 及 A/B 类不确定度评定；
  - 圆筒量筒无限广延边界修正：$\lambda_D = 1 + 2.4(d/D) \approx 1.121$；
  - 实用斯托克斯工作公式计算：$20.0^\circ\mathrm{C}$ 时蓖麻油黏滞系数 $\eta = 0.996\ \mathrm{Pa\cdot s}$（与标准值 $0.99\ \mathrm{Pa\cdot s}$ 误差仅 $0.6\%$）；
  - 雷诺数层流判据校验：$Re = \frac{d v \rho_0}{\eta} \approx 0.026 \ll 0.1$，严格证实斯托克斯定律前提成立；
  - 安德雷德 (Andrade) 黏度-温度经验指数规律拟合：$\eta = A e^{-B \theta}$，拟合度 $R^2 \approx 0.998$。

## 6. 赵海发教材按需轻量提取管道指南

针对体积庞大（517 MB）的赵海发《大学物理实验(第三版)》PDF 原版扫描件，平台开发了轻量、靶向的毫秒级抽取 CLI 管道：`scripts/extract_pipeline.py`。

### 6.1 核心原理：$+15$ 线性页码偏移模型
经全书比对测定：PDF 前 15 页为封面、前言、编辑说明与全书目录，正文第一页（教材 p.1）严格对应 PDF 第 16 页。  
由此确立了严格的数学映射：
$$\text{PDF 页码} = \text{书本印刷页码} + 15$$

### 6.2 CLI 常用命令示例

在终端中执行提取管道命令：

```powershell
# 1. 打印全书 65 门实验的清晰树状目录与页码索引
python scripts/extract_pipeline.py --list

# 2. 毫秒级靶向提取“液体黏度”实验切片
python scripts/extract_pipeline.py --exp "液体黏度"

# 3. 按实验序号提取“用准稳态法测定不良导体比热容”（实验二十八）
python scripts/extract_pipeline.py --exp 28

# 4. 一键批量提取重点四大目标实验（实验五、准稳态、夫琅禾费、声速）
python scripts/extract_pipeline.py --extract-all-targets

# 5. 指定外部自定义教材路径导出切片
python scripts/extract_pipeline.py --pdf "D:/教材/大学物理实验(第三版).pdf" --exp "声速" --out "extracted/sound_speed"
```

抽取结果将存放在 `extracted/` 目录下，包含各页的高清原图切片与 `manifest.json` 元数据清单。
